# Tekover — Freelance Data & AI Studio

Bold, modern marketing site for Tekover's freelance data analytics, ML, data science, and Gen AI services.

**Stack:** Next.js 15 · TypeScript · Tailwind CSS · App Router  
**Deploy:** Vercel (CI/CD from GitHub)

## Sections
- **Hero** — animated particle canvas, gradient headline, CTA buttons
- **Services** — Data Analytics, Machine Learning, Gen AI, Data Science
- **About** — studio story, values, tech stack
- **Contact** — enquiry form

## Local Dev
```bash
npm install
npm run dev
# http://localhost:3000
```

## Deploy to Vercel
1. Push this repo to GitHub
2. Go to vercel.com/new → import repo
3. Click Deploy — zero config needed

## Contact Form
`app/components/Contact.tsx` → replace `handleSubmit` with Formspree or Resend API route.
